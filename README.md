# داشبورد مانیتورینگ صندوق‌های سرمایه‌گذاری بورس ایران

سرویسی برای **دریافت زنده، ذخیره، اعتبارسنجی و نمایش تحلیلی** داده‌های صندوق‌های سرمایه‌گذاری بازار سرمایه ایران از منبع رسمی [TSETMC](https://tsetmc.com) (شرکت مدیریت فناوری بورس تهران).

این پروژه برای موقعیت **Quantitative Backend Developer** توسعه داده شده است و تمرکز آن بر سه مهارت اصلی است: **مهندسی داده (Data Engineering)**، **پردازش‌های مالی**، و **معماری نرم‌افزار تمیز و ماژولار**.

---

## ⚡ اجرای سریع

```bash
cp .env.example .env          # تنظیم متغیرهای محیطی (نام کاربری/رمز دیتابیس)
docker compose up --build     # ساخت و اجرای هر چهار سرویس
```

پس از بالا آمدن سرویس‌ها:

| آدرس | توضیح |
|---|---|
| `http://localhost:8000/` | داشبورد اصلی (Market Pulse، Heatmap، نمودارهای تحلیلی) |
| `http://localhost:8000/etf-live` | تابلوی معاملات زنده ETF |
| `http://localhost:8000/screener` | فیلترنویس (Screener) صندوق‌ها |
| `http://localhost:8000/health` | Health Check وب‌سرویس |
| `http://localhost:8000/docs` | مستندات خودکار API (Swagger) |

اجرای تست‌ها:

```bash
docker exec quant-fund-dashboard-web-1 python -m pytest tests/ -q
```

## 🧩 اجزای سیستم

| سرویس | مسئولیت | تکنولوژی |
|---|---|---|
| `web` | API و رابط کاربری (SSR + JSON API) | FastAPI + Jinja2 + Bootstrap RTL |
| `worker` | جمع‌آوری داده زنده و بک‌فیل تاریخچه | APScheduler |
| `db` | ذخیره‌سازی داده‌های صندوق و تاریخچه | PostgreSQL 15 |
| `redis` | کش داشبورد و داده‌های داغ | Redis 7 |

نمودار جریان داده (خلاصه):

```
TSETMC API ──► worker ──► PostgreSQL ◄──► web (FastAPI) ──► مرورگر
                    │            ▲
                    ▼            │
                 Redis (کش) ─────┘
```

## 📊 شاخص‌های کلیدی سیستم

- **~۵۰۰ صندوق** از ۱۰ نوع صندوق، دریافت و ذخیره‌شده
- **صندوق‌های سهامی (نوع ۶)**: به‌روزرسانی زنده **هر ۱ دقیقه**
- **بک‌فیل تاریخچه**: ۹۰ رکورد NAV به ازای هر صندوق از ابتدای فعالیت
- **شاخص کل بورس (TEDPIX)**: تاریخچه کامل از ۱۳۸۷ + به‌روزرسانی هر ۱۵ دقیقه
- **۸۵ آزمون خودکار** (unit / integration / regression)
- **امتیاز کیفیت داده** و پوشش دریافت در هر چرخه سینک
- **لایه اعتبارسنجی صحت داده**: ناسازگاری بین‌فیلدی، حرکت‌های غیرعادی NAV، شکاف زمانی و کهنگی — با قرنطینه خودکار رکوردهای بحرانی
- **نمودارهای تحلیلی**: مقایسه با شاخص، منحنی دراودان، جریان پول، نقشه ریسک/بازده، سری پریمیوم ETF
